# Game Design Draft

## High Concept

Maneuver Field Alpha 是一款原创机甲都市竞技手游原型，重点验证“人形/机甲单位在城市空间中的高速移动、射击和技能对抗”。

## Core Pillars

- 机动感：移动、冲刺、跃迁、空中调整要比普通射击游戏更爽快。
- 机甲感：角色体型、重量、武器反馈和技能表现要体现机械战斗差异。
- 都市战场：楼体、街区、高低差和掩体要服务于机动路线选择。
- 移动端优先：所有操作都先按手机触控体验设计。

## Prototype Scope

- 单个可操作机甲
- 单张灰盒城市测试地图
- 一套基础移动与摄像机系统
- 一把基础远程武器
- 一个位移技能
- 一个训练靶或简单 AI 目标

## MVP Gameplay Loop

1. 玩家进入训练场或小型城市测试场景。
2. 使用左侧虚拟摇杆控制机甲移动。
3. 使用右侧滑动区域控制摄像机和瞄准方向。
4. 使用射击按钮攻击目标。
5. 使用冲刺 / 推进技能进行快速位移。
6. 通过目标命中反馈、技能冷却和移动手感判断玩法是否成立。

## Initial Control Layout

- 左下：虚拟摇杆，负责移动。
- 右半屏：拖拽视角，负责摄像机旋转。
- 右下：普通射击、冲刺技能、跳跃 / 上升按钮。
- 中下：技能冷却、能量条或推进条。
- 顶部：调试用血量、目标距离、帧率信息。

## First Mecha Design

- 定位：均衡型测试机体。
- 武器：中距离连射能量枪。
- 技能 1：短距离推进冲刺。
- 技能 2：暂不做，避免早期范围失控。
- 核心参数：移动速度、转向速度、冲刺距离、射击间隔、武器扩散、命中伤害。

## First Map Design

- 类型：灰盒城市街区。
- 尺寸：先控制在单人测试可快速跑完的范围。
- 关键元素：直线路径、十字路口、低矮掩体、屋顶平台、坡道或跳台。
- 验证目标：移动是否爽、摄像机是否晕、射击距离是否舒服、冲刺是否有路线价值。

## Out of Scope for Early Prototype

- 正式角色池
- 商业化系统
- 排位系统
- 大规模联机
- 正式美术与完整世界观

## Design Risks

- 不要一开始做完整大逃杀或多人竞技，联网、地图、匹配和数值会把原型周期拉得过长。
- 不要直接复用任何现成商业游戏的角色、地图、UI、Logo、音乐或文案。
- 不要太早做正式美术，先用占位模型和灰盒验证玩法手感。
