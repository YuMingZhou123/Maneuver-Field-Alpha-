## Early Exit Criteria

Before expanding scope, the prototype should satisfy:

- [ ] Movement feels responsive on a real phone
- [ ] Camera control does not feel uncomfortable
- [ ] Shooting has clear hit feedback
- [ ] Dash / boost creates interesting movement choices
- [ ] The greybox map supports at least three useful routes
- [ ] Android build runs at acceptable frame rate on a mid-range device
