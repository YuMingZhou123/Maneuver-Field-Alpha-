# Pre-Production Plan

这份文档记录正式开发前需要完成的准备工作。目标不是一开始做大而全的游戏，而是先做一个能在手机上跑、能验证核心手感的 Unity 原型。

## 1. Product Definition

- 项目代号：Maneuver Field Alpha / Maneuver Field Alpha
- 正式名称：暂不确定，等核心玩法和世界观稳定后再定
- 平台优先级：Android 优先，iOS 后置
- 类型定位：原创机甲都市竞技手游
- 第一目标：验证机甲移动、第三人称摄像机、射击和冲刺手感
- 暂不承诺：正式联机、大逃杀规模、商业化、完整角色池

## 2. Prototype Boundaries

早期只做一条核心链路：

1. 打开游戏进入测试场景。
2. 操控一个机甲角色移动。
3. 调整视角并瞄准目标。
4. 使用普通射击攻击目标。
5. 使用冲刺 / 推进技能改变位置。
6. 在 Android 真机上验证帧率和手感。

不进入早期范围的内容：

- 多角色养成
- 大厅、登录、账号系统
- 匹配和排位
- 大地图大逃杀
- 皮肤和付费系统
- 正式剧情和完整世界观

## 3. Required Decisions Before Unity Setup

- Unity 版本：建议选择一个稳定 LTS 版本，团队成员保持一致。
- 渲染管线：建议使用 URP，便于移动端性能控制。
- 目标帧率：先以 60 FPS 为体验目标，同时保留 30 FPS 兜底。
- 屏幕方向：建议先横屏。
- 输入方案：先做触屏虚拟摇杆和按钮，不优先适配手柄。
- 资源策略：先使用占位模型、灰盒地图和临时音效。

## 4. Initial Task Checklist

- [ ] 安装统一版本的 Unity Editor
- [ ] 安装 Android Build Support
- [ ] 在仓库根目录创建 Unity 工程
- [ ] 设置包名，例如 `com.projectalph.prototype`
- [ ] 创建 `PrototypeScene`
- [ ] 创建 `MechaController` 脚本
- [ ] 创建虚拟摇杆 UI
- [ ] 创建摄像机跟随和拖拽旋转逻辑
- [ ] 创建目标靶和基础命中反馈
- [ ] 完成第一次 Android 真机包

## 5. Reference Rules

可以参考同类型游戏的体验方向，例如机甲速度感、城市空间、战斗节奏和移动端操作布局。但不能直接复制：

- 名字、Logo、宣传语
- 角色外观和设定
- 地图结构和标志性场景
- UI 布局和视觉风格
- 音乐、音效、语音、剧情文本
- 数值、技能名称和技能表现

更推荐的表达是：“受机甲都市竞技类玩法启发的原创移动端游戏原型”。

## 6. Definition of Done for Pre-Production

- [ ] 项目可以被 Unity 正常打开
- [ ] Android 可以成功打包
- [ ] 有一个可运行测试场景
- [ ] 有一个可操作机甲角色
- [ ] 有基础射击和冲刺
- [ ] 有一份手感问题记录
- [ ] 仓库文档能说明项目定位、范围和下一步任务
