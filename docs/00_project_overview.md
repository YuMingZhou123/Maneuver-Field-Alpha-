# 项目总览

## 项目名称

机动战场 Alpha（暂定名）

## 一句话定义

一款面向移动端的原创第三人称机甲竞技游戏。玩家以驾驶员形态探索都市战区，在资源、地形和安全区压力下选择召唤机甲，完成高机动射击与小队对抗。

## 核心边界

- 参考的是品类机制，不复制任何现有商业游戏的受保护内容。
- 首发目标平台为 Android，开发期同时支持 Windows 编辑器测试。
- 首个可玩版本是单机离线战斗原型，不在第一阶段引入正式多人服务。
- 模型源仓库为 `D:\\Git_Manage\\GitHub\\3Dmodel`，导入前必须核对每个资产的许可证。

## 里程碑

1. 文档与 Unity 工程初始化。
2. 单机战斗垂直切片：驾驶员、机甲、射击、敌人、地图、胜负。
3. 设备性能测试与移动端输入。
4. 小规模联机战斗验证。
5. 匹配、房间、服务器权威与内容扩展。
