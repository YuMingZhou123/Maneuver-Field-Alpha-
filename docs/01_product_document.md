# 产品文档

## 产品定位

机动战场 Alpha 是一款原创的科幻都市机甲竞技手游。它强调驾驶员和机甲两种战斗形态的切换，让玩家在“轻装游击”和“重装压制”之间做实时决策。

## 目标用户

- 喜欢第三人称射击、机甲和科幻都市题材的移动端玩家。
- 希望获得短局、高密度战斗与明确成长反馈的竞技玩家。
- 对复杂操作容忍度中等，愿意学习机甲技能组合的核心玩家。

## 核心体验

- 驾驶员在建筑、街道、屋顶和掩体间移动，侦察、搜集和交火。
- 能量与冷却达到条件后召唤机甲，改变生命值、移动能力和攻击方式。
- 安全区、补给与地形迫使玩家移动，持续制造遭遇和争夺。
- 机甲不是无条件优势：体型、冷却、能源和地形让驾驶员形态仍有战术价值。

## 玩法循环

1. 落入战区，选择初始路线。
2. 搜集维修、护甲、机甲能量和武器资源。
3. 以驾驶员形态侦察、游击并积累机甲能量。
4. 在关键位置召唤机甲，赢下据点或团战。
5. 跟随安全区移动，淘汰敌方单位。
6. 以最后存活的小队或积分领先者获胜。

## MVP 产品范围

- 一张小型都市测试地图。
- 一名驾驶员，一台默认突击机甲。
- 一种基础枪械和一种机甲主武器。
- 三类补给：维修、护甲、机甲能量。
- 三个 AI 敌人。
- 安全区、伤害、淘汰、胜负结算。

## 暂不进入 MVP

- 商业化、商城、皮肤、赛季通行证。
- 大地图百人模式。
- 公会、好友、排行榜和跨服匹配。
- 多机甲、多角色及完整成长系统。

## 原创化要求

- 世界观、机甲轮廓、角色设定、地图命名、美术风格和音效必须自研。
- 外部模型仅作为合法授权资产或原型参考，不可混入来源不明的商业资产。
- 所有第三方模型、贴图、动作与插件都要保留许可证和来源记录。
