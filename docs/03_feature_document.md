# 功能文档

## F-01 玩家控制

输入层统一映射移动、视角、射击、冲刺、跳跃、交互和召唤机甲。PC 使用键鼠，移动端使用双摇杆与技能按钮，但两端均调用同一套角色指令接口。

## F-02 驾驶员状态机

状态包括待机、移动、冲刺、跳跃、瞄准、射击、受击、倒地和淘汰。状态机只负责表现与动作切换，生命、伤害和武器由独立系统管理。

## F-03 机甲系统

机甲以 Prefab 形式存在，包含移动器、碰撞体、武器、生命系统和技能组件。驾驶员召唤时绑定控制权；退出或机甲被毁时安全返还驾驶员控制权。

## F-04 武器与伤害

- 驾驶员基础武器：中距离自动步枪。
- 默认机甲武器：中距离能量炮。
- 伤害结算统一由 Health 组件接收，避免武器互相依赖。
- 命中事件驱动特效、音效、飘字与镜头反馈。

## F-05 AI 敌人

AI 使用导航网格移动。行为优先级为：圈外回撤、低血量拉开、目标可见时攻击、目标不可见时搜索、无目标时巡逻。

## F-06 补给与安全区

补给使用可配置数据定义类型与数值。安全区控制半径、收缩节奏和圈外伤害，并向 UI 广播当前阶段。

## F-07 UI

HUD 显示生命、护甲、机甲能量、武器弹药、安全区信息和剩余敌人。移动端 HUD 与输入区分层，保证刘海屏和不同分辨率适配。

## F-08 多人联机路线

MVP 不接入正式联网。联机验证阶段实现小房间 2 至 4 人战斗，服务器负责位置校验、伤害、机甲状态和胜负判定；客户端只负责输入预测与表现。
