# Maneuver Field Alpha

> 暂定名：Maneuver Field Alpha
> 类型定位：原创机甲都市竞技手游
> 引擎方向：Unity

Maneuver Field Alpha 是一个面向移动端的 3D 机甲竞技游戏原型项目。当前仓库先作为 Unity 项目的开发代号与工程骨架，正式名称、美术风格、世界观和商业包装会在玩法原型稳定后再统一确定。

## 项目定位

- 平台：Android / iOS
- 引擎：Unity
- 类型：第三人称机甲动作 / 都市竞技 / 多人对战方向
- 当前阶段：早期原型
- 核心目标：先验证移动端操作手感、机甲移动、射击、技能和城市战斗空间

## 原创声明

本项目是原创游戏原型，与任何已上线或已停运商业游戏及其版权方无关联。项目可以参考同类型机甲竞技手游的体验方向，但角色、美术、地图、音乐、剧情、UI、数值和品牌表达均应保持原创。

## 第一阶段目标

- 搭建 Unity 移动端工程
- 实现虚拟摇杆与第三人称摄像机
- 制作一个基础机甲角色控制器
- 实现移动、冲刺、跳跃、射击和一个技能
- 搭建小型城市测试地图
- 完成 Android 真机打包测试

## 开发约定

- 当前名称仅为开发代号，后续可以统一改名。
- 不提交 Unity 自动生成的缓存目录，例如 `Library/`、`Temp/`、`Obj/`。
- 所有核心玩法先以灰盒和占位资源验证，不急于投入正式美术。
- 公开宣传时避免使用“复刻”表述，建议使用“原创机甲都市竞技手游原型”。
