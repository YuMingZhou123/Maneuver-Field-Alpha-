# Maneuver Field Alpha 3D Browser Demo

This is an original Three.js 3D mecha-city gameplay prototype. It is a visual
and interaction reference for the future Unity implementation, not a copy of
any existing game's characters, assets, maps, UI, or names.

Run `npm install`, then `npm run build`. Serve this folder using any static
HTTP server and open `index.html`.

Desktop: WASD or arrow keys to move, mouse to rotate the third-person camera,
left click to fire, Shift or Space to boost, and R to restart.

Touch: use the left virtual stick, drag on the scene to rotate the camera, and
use the FIRE and BOOST buttons.
