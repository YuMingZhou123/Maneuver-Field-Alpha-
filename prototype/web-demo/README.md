# Maneuver Field Alpha Browser Demo

This is an original Canvas-based gameplay prototype. It validates the core
mecha-city skirmish loop before the same systems are implemented in Unity.

Open `index.html` in a modern desktop or mobile browser. No build step is
required.

Desktop: WASD or arrow keys to move, pointer to aim, click to fire, Shift or
Space to boost, and R to restart.

Touch: use the left virtual stick, drag in the arena to aim, and use the FIRE
and BOOST buttons.
